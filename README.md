# 跳广告 · 长辈手机视频号拦截

> **本工具由 大肥鱼 生成。**
> 一个装给家里老人手机用的小工具：**让微信「视频号」打不开**，桌面名称和图标都很普通，不会被长辈察觉。

## 这是什么

家里老人迷上微信视频号，一刷就是几小时、外放声音大、还容易点到直播买东西。
视频号不是独立 App，没法单独卸载，也没有开关能关掉。

这个工具用 Android 的**无障碍服务**做一件事：

> 只要微信打开了视频号相关页面，立刻把它退回去。

- 在群里点开别人分享的视频号 → **立刻回到群聊**
- 在「发现」页点开视频号 → **立刻回到发现页**
- 连续点 3 次 → 直接送回桌面

实测在华为 / 荣耀（HarmonyOS 4 / EMUI，Android 12）上可用。

## 安装

下载 [out/tiaoguanggao-v1.4.apk](out/tiaoguanggao-v1.4.apk)，传到手机点开安装（需允许「未知来源」）。

或者用 adb：

```bash
adb install -r -d out/tiaoguanggao-v1.4.apk
```

## 配置（约 2 分钟）

1. 打开「跳广告」，输入密码 **1234**，**进去第一件事就是改密码**。
2. 点 **① 开启跳过服务** → 跳到系统的无障碍列表 → 找到「跳广告」→ 打开开关 → 允许。
3. 选拦截方式：
   - **退回上一页**（推荐）：从群里点开就回群聊
   - **直接回桌面**
4. 点 **打开微信，试一下效果**，再回 App 确认「已拦截」次数在涨。

### 华为 / 荣耀 / 小米 等激进机型建议

> 设置 → 应用 → 应用启动管理 → **跳广告** → 关闭「自动管理」→ 手动勾选 **自启动 / 关联启动 / 后台活动**

如果发现服务老是被系统杀掉，可以在 App 里打开「**后台常驻**」——
代价是通知栏会多一条常驻通知，这就是我们默认关掉它的原因。

## 出问题怎么办

App 里点「**★ 查看 / 复制诊断信息**」，会生成一份完整时间线：

```
15:14:33  com.tencent.mm.plugin.finder.ui.FinderShareFeedRelUI
15:14:33  >> 命中 FinderShareFeedRelUI [类名] → 退出流程
15:14:33  >> 按返回 第1次（当前 FinderShareFeedRelUI）
15:14:34  com.tencent.mm.ui.chatting.ChattingUI
15:14:34  >> 检查 → ChattingUI（已退出）
```

`>>` 是本工具的动作，其余是微信的窗口变化。按这个提 Issue 我能直接定位。

| 现象 | 含义 |
|---|---|
| `系统开关：未开启` | 无障碍没开 |
| `系统开关：已开启` + `服务连接：从未连接` | 服务被系统杀了，看上面「应用启动管理」 |
| `其中微信 0 条` | 收不到微信事件（可能在应用分身里） |
| `其中微信 N 条` 但 `已拦截 0 次` | 微信换了类名，把上面的时间线发我 |

## 补充建议：微信自带的青少年模式

微信内置的「青少年模式」会把视频号入口**整个隐藏**，不用装任何东西、不会闪退。
和本工具一起用效果最好：

> 微信 → 我 → 设置 → 青少年模式 → 开启 → 设一个只有你知道的 4 位密码

---

## 原理

微信的视频号（含视频号直播）都在它的 `finder` 插件里，所以只要判断当前窗口的类名里有没有 `finder`，
再执行一次「返回」就能把它弹掉。细节和踩过的坑都写在 **[docs/NOTES.md](docs/NOTES.md)**。

## 自己编译

**不需要 Android Studio，不需要 Gradle。** 只用 aapt2 + javac + d8 + zipalign + apksigner：

```powershell
pwsh -ExecutionPolicy Bypass -File build.ps1
```

需要先准备工具链（脚本里说明了来源和版本，都是 Google 官方 CDN 直接下载解压）。
